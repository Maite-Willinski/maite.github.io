## 🚀 Funcionalidades Clave Desarrolladas

- 🌓 **Selector de Tema Dinámico:** Código JavaScript encargado de alternar los estilos de la interfaz entre modo oscuro y claro de forma fluida mediante la mutación de variables CSS en tiempo real.
- 📋 **Validación en el Lado del Cliente:** Control estricto del flujo de datos del formulario de contacto para asegurar que la información ingresada cumpla con los formatos requeridos antes de procesar el envío.
- 📱 **Diseño Adaptativo Eficiente:** Arquitectura modular basada en CSS3 (Flexbox y Media Queries) que reestructura las secciones de forma armónica según las dimensiones de la pantalla.

## 🖥️ Relación con la Administración de Sistemas (SMR / ASIR)
> 🗄️ **Arquitectura Ligera:** Al no utilizar frameworks pesados (como React o Angular), la transferencia de archivos a través de HTTP es sumamente eficiente, lo que reduce drásticamente el uso de ancho de banda en el servidor de producción.
> <br><br>
> 🐋 **Estrategia de Despliegue:** Al estructurar el código en una raíz estática limpia, es ideal para ser empaquetado en un contenedor **Docker** corriendo sobre una imagen alpina de **Nginx**, agilizando pipelines de integración y entrega continua.
