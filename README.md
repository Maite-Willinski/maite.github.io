## 🔮 Sobre este Proyecto

Este repositorio aloja el código fuente de mi **Página Web Personal**, desplegada de forma nativa a través de GitHub Pages. 

Tras consolidar mis conocimientos de hardware, redes y protocolos en **SMR**, decidí diseñar este espacio de forma autodidacta para explorar las bases del desarrollo de interfaces visuales. Funciona como mi laboratorio estático experimental, donde priorizo la armonía cromática lila, la limpieza en las hojas de estilo (CSS) y una maquetación responsive fluida.

---

## 🚀 Características Técnicas & Buenas Prácticas

*   **Estructura Semántica Estricta:** Uso nativo de etiquetas HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`) para asegurar la accesibilidad y un correcto indexado (SEO).
*   **Diseño Adaptativo (Responsive):** Estilos CSS estructurados mediante selectores modernos y técnicas de diseño fluido para garantizar una visualización óptima en pantallas móviles, tablets y monitores de escritorio.
*   **Control de Versiones Limpio:** Ramificación optimizada mediante Git para realizar un seguimiento lógico de las fases de diseño y maquetación.

## 🖥️ La Perspectiva de Sistemas (ASIR / SMR)

Desde el punto de vista de la administración de sistemas, este proyecto estático representa un excelente caso de estudio de **arquitectura web ligera**:
*   **Carga Optimizada:** Al no arrastrar frameworks pesados ni scripts redundantes, el servidor procesa y sirve las peticiones con tiempos de respuesta (*TTFB*) bajísimos.
*   **Producción Lista:** Su estructura limpia modular es ideal para ser empaquetada e integrada directamente en un volumen de contenedores **Docker** o para ser servida a gran velocidad mediante configuraciones de **Nginx** o **Apache** en servidores corporativos Linux.
